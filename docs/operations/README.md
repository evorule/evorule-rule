# operations/ — 运维与发布

> **面向部署、测试、发布、运维的开发者**。

## 写什么

- 构建命令、CI/CD 配置说明
- 测试策略、test runner 使用
- 发版流程、release checklist
- 监控、告警、备份、灾难恢复(runbook)

## 不要写在这里

- ❌ 用户/开发者使用文档 → 去 [tutorial/](../tutorial/) 或 [how-to/](../how-to/)
- ❌ 架构决策与原理 → 去 [adr/](../adr/) 或 [explanation/](../explanation/)

## 命名规范

`主题.md`(如 `testing.md`、`build-and-deploy.md`、`release-process.md`),
**不**带日期 —— 流程变了改文件,不改文件名。
